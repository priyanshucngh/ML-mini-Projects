📚 Projects

1. Student Academic Performance Prediction

Description:
A Machine Learning-based classification project that analyzes student-related attributes and predicts academic performance categories.

Key Highlights:

- Dataset preprocessing and exploratory data analysis.
- Academic performance classification into At Risk, Average, and Good categories.
- Implementation of Decision Tree and Random Forest classifiers.
- Model evaluation using classification metrics.
- Feature importance analysis.

Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.
